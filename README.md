# Sesión DJ — Fiestas de San Justo 🎧

Set list interactivo para las fiestas de San Justo, Zamora. Soul · Funk · Disco · Electronic · 80s–90s.

## Cómo usar

1. Abre `sesion-dj-san-justo-v3.html` en el navegador
2. **Marca los temas** que ya has pinchado haciendo clic en cada track
3. **Reordena** arrastrando por el icono ⠷ de la izquierda
4. **Ordena por BPM** con el botón en cada bloque
5. El orden y las marcas se guardan automáticamente en el navegador (localStorage)
6. Para empezar de cero: botón "Reiniciar marcas" (arriba)

## Estructura

| Bloque | Género | BPM |
|--------|--------|-----|
| 01 — Pop Reconocible | Pop 80s-90s | 88 → 121 |
| 02 — Soul Roots | Soul & R&B | 88 → 120 |
| 03 — Pure Funk | Funk underground | 90 → 120 |
| 04 — Disco | Disco clásico | 115 → 126 |
| 05 — Rare Groove | Disco raro / proto-house | 103 → 124 |
| 06 — Nu-Jazz → House | Transición | 108 → 130 |
| 07 — House & After Hours | House / late night | 127 → 83 |

Bloques 1–5: sesión base (~5h). Bloques 6–7: extensión.

## Basado en

- Colección de vinilos de 329 discos (175 singles, 12" y maxis)
- Análisis de Funky Collector series (Parts 12, 13, 17, 19)
- Caras B y versiones extendidas identificadas track a track
